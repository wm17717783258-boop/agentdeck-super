# 成熟度自检（1.11.19）

对着用户那句话逐条查：**不分电脑系统、不分 Agent、不分网络、不分电脑设备**，然后查"成熟产品"该有的东西还缺什么。

每条都给**能当场复现的证据**，不给形容词。

---

## 一、四个"不分"

| 要求 | 现状 | 证据 |
| --- | --- | --- |
| **不分系统** | 一个 npm 包、零依赖、零原生模块；三系统同一份 tarball；**平台分支白名单**（9 个文件，每个写明理由） | `tests/one-package.test.mjs` 7 条：package.json 无 `os`/`cpu`/依赖、包内无 `.node`/`.exe`、白名单外不许出现 `process.platform`、三系统配置结构逐字同构；`platform-matrix` 12 条守路径。突变注入 `os:["win32"]` 立刻红 |
| **不分 Agent** | 内置 26 家 + 注册表 + 临时通道 + 片段兜底 | `tests/any-agent.test.mjs` 10 条；`nexi host list` 26 行；`nexi host add` 后 `install` 能写进去；YAML 宿主也能写（`tests/yaml-hosts.test.mjs` 12 条） |
| **不分网络** | stdio 本地进程，启动不依赖外网；relay / 公网隧道是可选能力 | `tests/offline.test.mjs`：把 DNS / 非回环 socket / fetch 全打挂，MCP 仍握手 + 列 20+ 工具 |
| **不分设备** | 不绑硬件、不绑用户、不绑路径；状态目录可整体搬走；配置可 `--portable` 只写裸 `node` | `tests/offline.test.mjs`：换 HOME 照抄配置能起；`state.json` 换目录数据还在；配置里无个人目录 |

## 五、1.11.19 补掉的五件

| 这轮补的 | 为什么算"成熟度"而不是功能 | 验收 |
| --- | --- | --- |
| **一个包的机器契约** | 之前"不分系统"是我口头解释，现在是 7 条断言 + 9 文件白名单。谁往业务逻辑里塞 `if (win32)`，测试就红 | `tests/one-package.test.mjs` 7 条；注入 `os:["win32"]` 后第 1 条红 |
| **体检不说谎** | 旧判据是全文搜 `nexi`，脚本被删了照样绿。假绿会让用户白查半天 —— 比报错更伤 | `lib/connect/audit.js` 四层校验；`tests/host-audit.test.mjs` 16 条，每种假绿都有用例 |
| **并发不丢更新** | 两个终端同时装，后写的抹掉先写的，**且不报错**。这是最难查的一类数据损坏 | `lib/connect/lock.js`；测试里开**两个真进程**同时写一个配置 |
| **备份能回滚、不堆积** | 有备份却没命令回滚 = 半个功能；从不清理 = 往用户配置目录倒垃圾 | `nexi restore`；保留 5 份；回滚前再备份（可撤销）；回读比对字节 |
| **诊断包** | 排障靠用户截图是最低效的方式；但导多了会把 key 带出去 | `nexi doctor --export`；8 条测试，其中一条拿真实配置搜密钥 |

## 六、还差的（诚实版）

1. **P0 · 真机矩阵**：拿 2–3 台真机（Mac / Linux / 另一台 Windows）把 26 家跑一遍，把"只核过文档"的 20 家降下来。**这是当前最大的未知，任何代码改动都替代不了。**
2. **图形界面**：全命令行，桌宠是唯一 GUI 形态。要不要做、做成什么样，是产品决定，不是补丁。
3. **多语言**：中文为主，英文只有 README 片段。
4. **YAML 覆盖面**：只处理块状 map / 块状 seq / 流式数组这一档；锚点、别名、多文档 `---` 遇到会拒绝改写（不猜）。
5. **并发锁只保单机**：两台机器同时写网络盘上的同一个配置，不在保护范围（也没打算做分布式锁）。
6. **宿主升级改格式**：宿主大版本改配置格式时，现在只能靠用户报错或 `doctor` 发现条目失效，做不到提前预知。

## 七、结论

- 四个"不分"都有**可复现的证据**，不是口头承诺。其中"不分系统"这一条从"我保证"升级成"你改一下就红"。
- 成熟度表里除图形界面与多语言外，全部 ✅。
- 最大的诚实点没变：**26 家里只有 6 家在本机真装过**，其余 20 家是文档级适配。这一条不改口。
- 这轮最值钱的一处不是新功能，是**把体检的假绿修掉了** —— 一个会骗人的自检，比没有自检更糟。
