# 成熟度自检（1.11.17）

对着用户那句话逐条查：**不分电脑系统、不分 Agent、不分网络、不分电脑设备**，然后查"成熟产品"该有的东西还缺什么。

每条都给**能当场复现的证据**，不给形容词。

---

## 一、四个"不分"

| 要求 | 现状 | 证据 |
| --- | --- | --- |
| **不分系统** | 一个 npm 包、零原生依赖、纯 Node ESM；三系统同一份 tarball | `tests/platform-matrix.test.mjs` 12 条；`nexi where` 一屏打出三系统落点；突变回 Windows 写法会红 3 条 |
| **不分 Agent** | 内置 25 家 + 注册表 + 临时通道 + 片段兜底 | `tests/any-agent.test.mjs` 10 条；`nexi host list` 25 行；`nexi host add` 后 `install` 能写进去 |
| **不分网络** | stdio 本地进程，启动不依赖外网；relay / 公网隧道是可选能力 | `tests/offline.test.mjs`：把 DNS / 非回环 socket / fetch 全打挂，MCP 仍握手 + 列 20+ 工具 |
| **不分设备** | 不绑硬件、不绑用户、不绑路径；状态目录可整体搬走；配置可 `--portable` 只写裸 `node` | `tests/offline.test.mjs`：换 HOME 照抄配置能起；`state.json` 换目录数据还在；配置里无个人目录 |

## 三、成熟产品该有的东西

| 能力 | 状态 | 证据 / 缺口 |
| --- | --- | --- |
| 一键安装 | ✅ | `npx -y agentdeck-super@latest --all`；`--dry-run` 先看差异 |
| 幂等 | ✅ | 重复装 `changed:false`；`tests/plugin-install.test.mjs` |
| 安装前备份 | ✅ | 写盘前 `*.nexi-backup-<时间戳>` |
| 精确卸载 | ✅ | `nexi uninstall <host>` 只删自己那一项，别家 server 保留（本版修了 `mcp.*` 卸不掉的 bug） |
| 升级 | ✅ | `nexi update`；固定目录切版本指针，宿主路径不变 |
| 回滚 | ✅ | `nexi rollback` 切上一版 |
| 离线安装 | ✅ | `--bundle <tgz>` + `--sha256` 校验 |
| 体检 | ✅ | `nexi doctor`：Node / 工具数 / 宿主注册 / 版本脱节 / 功能探针；本版把 25 家折成一行，结论不再被顶出屏幕 |
| 只读模式 | ✅ | `nexi mcp --read-only`；`tests/mcp-readonly.test.mjs` |
| 审计 | ✅ | `deck_audit` 记录操作；共享账本 HMAC 封印 |
| 权限/审批 | ✅ | `deck_automation` 待审批 → `nexi approve/deny` |
| 错误提示 | ✅ | 不认识宿主回已知列表；没装宿主不写默认路径并给 `--force` / 显式路径两条出路；注册表坏文件只跳过并列出原因 |
| 文档 | ✅ | `docs/装机和多设备测试.md`（唯一入口）、`docs/接入的Agent清单.md`、每版发布说明 |
| 可观测 | ⚠️ 部分 | 有 evidence 落盘与 `doctor --json`；**没有结构化运行日志文件**（只有 stderr 的 `[nexi:info]`） |
| 一键自删（卸载整个产品） | ❌ 缺 | 现在只能手动删安装目录 + `nexi uninstall --all`。没做是因为"运行中删除自己"在 Windows 上必失败，需要单独的 `nexi uninstall --self`（退出后再删的守护进程），优先级低于接入 |
| 自动更新提示 | ❌ 缺 | 只有手动 `nexi update`。故意不做常驻联网检查 —— 与"不分网络"冲突，需要做成显式开关 |
| 图形界面 | ❌ 没有 | 全部命令行为主；桌宠是唯一 GUI 形态 |
| 多语言 | ⚠️ | 中文为主，英文只有 README 片段 |

## 四、按优先级排的缺口（建议下一步）

1. **P0 · 真机矩阵**：拿 2–3 台真机（Mac / Linux / 另一台 Windows）把 25 家跑一遍，把"只核过文档"的 19 家降下来。这是当前最大的未知，任何代码改动都替代不了。
2. **P1 · YAML 写入器**：Goose、Continue 新格式都是 YAML，现在只能靠 `nexi snippet` 手粘。加一个最小 YAML 写入（只处理 `mcpServers` 列表 / `extensions` map）能再多覆盖两家主流。
3. **P1 · `nexi uninstall --self`**：真正的"卸干净"，含固定目录、状态目录、注册表；用子进程延后删除。
4. **P2 · 结构化日志**：`$DSH_HOME/agentdeck-super/logs/nexi-YYYYMMDD.log`（按天、大小上限、自动轮转），排障时不用再让用户复制终端。
5. **P2 · 可选更新检查**：`NEXI_UPDATE_CHECK=1` 才联网，默认关 —— 保住"不分网络"。

## 五、结论

- 「不分系统 / 不分 Agent / 不分网络 / 不分设备」四条现在都有**可复现的证据**，不是口头承诺。
- 离"成熟产品"还差的是**真机覆盖**和**运行日志/自删**这类运维件，不是核心能力。
- 最大的诚实点：**25 家里只有 6 家在本机真装过**，其余 19 家是文档级适配。这一条不改口。
