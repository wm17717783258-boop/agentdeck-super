# 商业化与基础设施设计（v1 讨论稿）

> 结论先说：**插件市场没有支付功能**，它是公开索引（npm/GitHub 引用），所以"在商店里标价卖"这件事不存在。
> 能收钱，但收的是**我们服务端的东西**，不是本地代码里的开关。
> 本文回答三个问题：免费版给什么、Pro 怎么收、要建多少基础设施（**多数情况下不需要网站**）。

---

## 1. 市场的事实（已核验）

| 事实 | 影响 |
| --- | --- |
| 目录条目是 npm 包 / GitHub 仓库引用，没有任何 `price`、`paid`、`purchase` 字段（本机 1.26 MB 目录文件里这些键出现 0 次） | 不能标价、不能内购 |
| 收录靠给 `awesome-dsh-plugin` 提 PR（4200+ 插件），要求：`dsh plugin add` 能装、声明 `dsh.bundle`、描述与实际一致、分类正确、有人维护 | 免费 = 换流量，交易逻辑自己写 |
| 插件代码在用户机器上以用户权限运行（官方免责声明明确"收录不是安全审查"） | 任何**本地**功能限制都能被改 JS 绕过 |
| 宿主提供 LLM 服务与凭据管理 | 用户可以自带 key → 我们不必替他付模型钱 |

**设计红线**：不要做"本地解锁付费功能"。要么卖授权（提高门槛，适合低价买断），要么卖服务端资源（真正拦得住）。

---

## 2. 免费版 vs Pro

### 免费版（上架市场的那一版）
- 超级 Agent 本体：工具带（文件/命令/检索/网页/任务板）+ 自主循环
- 小组协作：最多 **3 名成员**、顺序执行、单团队
- 任意 Agent 接入：本机 CLI + ADBP 桥 + OpenAI 兼容（自填 key）
- 任务板可视化 + 运行记录
- 这条线要足够好用——它负责传播，不负责赚钱。

### Pro（订阅云额度）
- 小组人数不设限（10/20）、**并行车道**、多团队
- 云端编排：任务板云同步、跨设备继续跑、团队共享任务板
- 托管模型额度：不用自己配 key，按量扣额度
- 长任务无人值守、定时/流水线、运行审计导出
- 优先队列 + 失败自动重试策略

### 建议定价（可 A/B）
- 月付 ¥29~39：额度包（如 500 万 token / 月 + 5 席位）
- 年付 ¥299：性价比锚点
- 团队版 ¥199/月：10 席位 + 私有部署文档
- 学生/开源作者：凭仓库链接送额度（换口碑）

## 3. 收费基础设施：三级跳

### 第 0 级：零后端（今天就能上线）
卖「激活码」：离线签名串（Ed25519），插件内置公钥校验。
- 不需要网站，不需要服务器。
- 收款：知识星球/爱发电/淘宝/微信收款码，手工或半自动发码。
- 限制：不能按量计费、不能远程吊销、能被高手破解。
- 适用：**验证有没有人愿意付钱**。

### 第 1 级：轻后端（推荐的第一版）
一个 Cloudflare Worker（或 Vercel 函数）+ 一张表（D1/KV/Postgres），几十行：
```
POST /v1/activate   {code, deviceId}  → {token, plan, quotaLeft}      # 卡密换 token
POST /v1/usage      {token, tokens}   → {quotaLeft}                   # 用量上报
GET  /v1/models                        → 我们签发的可用模型清单
POST /v1/chat/completions             → 模型网关（可选，按量扣额度）
```
- 插件每 N 分钟校验一次 token + 额度；额度用尽降级到免费版。
- 成本：Workers/D1 免费额度足够早期；域名可选（`xxx.workers.dev` 免域名）。
- **仍然不需要网站**：下单页用现成知识付费平台，用户拿卡密。
- 需要网站的时刻：要自助注册、开发票、团队邀请、用量看板——那时才做（一个静态页 + 上面这些接口就够）。

### 第 2 级：完整 SaaS
账号体系、订单/支付回调（微信支付需企业主体；个人先用知识付费平台代收）、席位管理、账单、审计。到这一级才值得建站和备案。

**给用户的一句话**：现在不用建网站；先有 npm 账号（发包装插件，免费注册）+ 一个收款方式（哪怕收款码）；等真有人按月付了，再花两天搭那个 Worker。

## 4. 云额度怎么扣（技术方案）

两条可选路线，建议先 B：

- **A. 全托管**：用户不填 key，所有模型调用走我们的网关 `POST /v1/chat/completions`，网关按 token 扣额度。体验最好，我们先垫付模型费，需要现金流。
- **B. 混合（推荐）**：用户可自带 key（免费、我们零成本）；Pro 用户可用我们的网关额度（付费）。插件里 `brain.mode` 天然支持 `host / api / cli` 三模式，把 `api` 的 `baseUrl` 指向网关即可，无需改代码。

额度扣减点放在网关，插件只上报用量；插件被破解也只能拿到"它自己已有的额度"，偷不走未购买的额度。

## 5. 上架清单（免费版）

1. npm 账号 + （建议）组织 scope，例如 `@agentdeck`
2. `npm publish --access public`（包名 `agentdeck-super` 已确认在 npm 上未被占用）
3. 给 `awesome-dsh-plugin` 提 PR：
   - 条目：名称、一句话描述、分类（多 Agent / 编排）、npm 包名、仓库、`dsh.bundle` 声明、兼容版本
   - 必须真能 `dsh plugin add agentdeck-super` 装成功（他们会实测）
   - 附中英 README + 截图/GIF
4. 可选：自建索引源（format-1 `index.json` + `DSHM_REGISTRY_URL`），不依赖收录也能被别人一键添加
5. 免责与隐私：插件会在用户机器上跑命令 → README 必须写清「它做什么、不做什么、需要什么权限」

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 被破解 | 只把收费绑在服务端资源上；本地只留激活态 |
| 用户嫌贵 | 免费版必须能单独把活干完；Pro 卖"省事"和"规模" |
| 模型费用倒挂 | 默认引导自带 key；额度包定价按 2.5~3 倍成本 |
| 平台政策变化（市场/收录规则） | 同时铺 npm + 自建索引源 + 官网直下，不依赖单一入口 |
| 安全投诉（插件能跑命令） | 危险命令需二次确认、默认工作目录沙箱、全量操作日志可导出 |
