# Nexi 灵犀 1.11.5 发布说明

发布日期：2026-11-09  
包名：`agentdeck-super`  
交付包：`agentdeck-super-1.11.5.tgz`

## 这版解决什么

这不是再堆一个工具，而是把“换一台电脑还要重新找路径、升一次级宿主配置就失效”
这条安装链改成可反复验证的固定流程：

- 固定安装目录：Windows `%LOCALAPPDATA%\Nexi`，macOS
  `~/Library/Application Support/Nexi`，Linux `~/.local/share/nexi`；
- 宿主配置只写稳定启动器 `<安装目录>/bin/nexi.mjs`；
- 新版本先解到 staging，校验关键文件后原子切 `current.json`；
- 坏包不覆盖当前能跑的版本；
- 旧版本保留，`nexi rollback` 可回退；
- 新增 `nexi pair host|guest|check|sync`，装完直接在任意一台设备做双机配对；
- 配对状态固定放 `<安装目录>/pair`，升级不丢；
- `package.json` 新增 `nexi-pair` bin，npm 全局安装也能直接调用；
- 稳定启动器设置 `NEXI_INSTALL_HOME`，自定义 `--home` 安装后 `version/update/rollback` 不会掉回系统默认目录。

## 最短使用

已解包的交付目录：

```powershell
node install.mjs
node "$env:LOCALAPPDATA\Nexi\bin\nexi.mjs" doctor
node "$env:LOCALAPPDATA\Nexi\bin\nexi.mjs" pair help
```

用 tgz：

```powershell
node install.mjs --bundle .\agentdeck-super-1.11.5.tgz
```

npm 上架后才成立的命令：

```powershell
npx -y agentdeck-super@latest --all
```

改完源码继续测：

```powershell
node install.mjs --no-hosts
```

或改完重新打包后：

```powershell
npm pack --pack-destination .
node "$env:LOCALAPPDATA\Nexi\bin\nexi.mjs" update --bundle .\agentdeck-super-1.11.5.tgz
node "$env:LOCALAPPDATA\Nexi\bin\nexi.mjs" rollback
```

## 诚实边界

1. **npm / MCP Registry / GitHub Release 还没有发布。** 当前 npm 查询是 404，
   本机没有 npm 登录态、没有 GitHub token。不能把“代码支持”写成“已经能搜到”。
2. **不存在所有主流 Agent 共用的插件搜索框。** 一次发布、一个包、一个安装入口，
   不等于所有宿主共用一个市场；各宿主仍然各写各的 MCP 配置。
3. **8 个宿主适配器不等于 8 家都真机认证。** 本机真实认证只有 Codex；其余宿主
   未安装就不伪造配置。
4. **没有第二台物理电脑。** 双机测试是同机两个独立目录/身份/进程，走真实 relay
   和局域网网卡；物理双机仍需用户按 `任意Agent-安装与改测-最短路径.md` 实跑。
5. **席位不是无限。** free 3 / plus 8 / studio 30 / business 200，每台设备 1 席；
   同一邀请目前不能按员工单独签发/撤销。
6. **收入链路没有真实商户扣款。** 支付/退款/对账/发票数据有本地真 HTTP 验收，
   但本机没有商户号和支付账号，不能宣称“真钱已到账”。
