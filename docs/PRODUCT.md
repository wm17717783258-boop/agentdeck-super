## 2. 为什么用户会留下（留存设计）

留存不是靠"功能多"，而是靠**四件每天都会发生的小事**：

1. **桌宠越用越像你**（进化）。第一周它只是个图标；第四周它会在你开工前把那三件你每天都要做的事列出来。这种"沉没成本"是留得最牢的——档案可以导出带走，但重练一个要花一个月。
2. **邀请即席位，拉人零成本**。房主付钱、朋友白嫖进来干活（客人不需要授权码）。每一次"帮我看看这个"都是一次传播，且被邀请的人一旦干过一次活，下次自己派活时就是付费候选。
3. **房间是活的**。任务、聊天、串门记录都留在房间里，关掉就没了，所以大家会一直开着。房间里的人越多，单个人越走不掉。
4. **皮肤是收集品**。免费 3 套够用，付费那套是身份标识（在房间里别人看得见）。

配套动作（本周就能上）：开工时一句「今天三件事」的每日站会、任务完成后的成就播报、串门带回来的"隔壁在做什么"。

## 5. 诚实边界（写给自己，不写进宣传）

- 市场上同类有 ~30 个 agent 编排插件、39 个桌宠插件，DSH 原生已有 Agent Teams。**我们不是唯一**，差异化在：异构成员（不是只认自家 subagent）、多方房间（不是单机）、邀请即席位、桌宠串门。别拿"首创"当卖点，拿"能一起干"当卖点。
- 桌宠的"进化"是统计出来的习惯，不是真学习；文案写"越用越顺手"，不写"自我意识"。
- 跨机同步靠中继，**房间里的人默认互相信任**（同团队场景）；别宣传成"安全隔离的多租户"。
- 授权码能被破解（本地 JS 拦不住高手）。所以只把**服务端资源**（建房、额度）绑授权，本地只留激活态；破解者也就能自己建房，抢不走我们的模型额度。
