# Nexi 灵犀 1.11.15 发布说明

发布日期：2026-11-10
包名：`agentdeck-super`

## 这版只做一件事：别让用户停在命令行

1.11.14 把"Agent 也能看见房间"接通了，但命令行的收尾提示还停在旧话术：

```
进房并同步成功，已占用 1 席（乙机）。现在两边都跑一次：
  npx -y agentdeck-super@latest pair check
```

用户照做，`check` 说"连得上"，然后关窗口收工 —— **永远发现不了 Agent 已经能看见房间**，
下次又在 Agent 里撞上"房间里有谁？不知道"。

## 两处改动

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| `pair host` / `pair guest` 收尾 | 只说"跑 check" | 多一行：「回你常用的 Agent 里问『房间里有谁？』—— 它应该答出成员 2 人」 |
| `pair check` | 只报中继可达性 | 多一行 `Agent 那边：已进房 xxxx…（2 人）`，直接读机级房间记录 |

`pair check` 这一行是**只读**的：不发请求、不改状态，读不到就明说读不到，不影响配对结论。

## 验证

`tests/pair-agent-visible.test.mjs` 增加一条断言：配对完成后跑 `pair check`，
输出必须包含 `Agent 那边：已进房`。行为没变，断言多一道，防止以后有人把这行删掉。

## 边界

同前：没有第二台物理电脑，仍是同机两个独立进程 + 真实网卡地址；macOS/Linux 未测。
