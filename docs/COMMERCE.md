# 真实收款手册（零后端即可开卖）

> 目标：**今天就能收到第一笔钱**，不需要网站、不需要企业主体、不需要支付接口。
> 只有三样东西：一个收款码（或爱发电主页）、一个能签授权码的脚本（已经写好了）、一段发给客户的话。

## 2. 卖出第一单：完整流程（每单 1 分钟）

客户在爱发电/微信付了 ¥29，然后把订单号发给你。你做三件事：

```powershell
# ① 签一张码（--days 365 是有效期，--seats 8 是名额，按档位给）
cd D:\agentdeck-super
node tools/license-cli.mjs issue --tier pro --to "客户名字" --days 365 --seats 8

# ② 自检一下（看输出里有没有"有效"、档位对不对）
node tools/license-cli.mjs verify ADSK1.xxxxx

# ③ 记一笔订单（可选，纯本地记账，方便续费时找人）
node tools/license-cli.mjs orders
```

拿到 `ADSK1.…` 那一长串，**原样**发给客户（下面有现成话术）。客户在 DSH 里粘一次就激活了：

```
/ deck license activate ADSK1.…
```
（命令实际是 `/deck` 后跟 `license activate <码>`；插件里也可以让桌宠代办："把我的授权码激活一下"。）

## 5. 什么时候需要写后端（第 1 级）

现在这套（离线签名 + 手工发码）能撑到**月流水几千块**。出现下面任一情况再上 Worker，别提前：

- 一天要发 10 张以上的码（手工烦）
- 要按量卖模型额度（需要在服务端扣）
- 要远程吊销（有人公开传播自己的码）
- 要自助续费/发票

那时的接口（已经设计好，约 200 行）：
```
POST /v1/activate  { code, deviceId } → { token, plan, exp, quotaLeft }
POST /v1/usage     { token, tokens }  → { quotaLeft }
POST /v1/rooms     Bearer token       → { roomId, inviteUrl }   # 建房配额也在服务端卡
POST /webhook/afdian                  → 付款成功自动签码 + 邮件/微信发货
```
**关键设计**：额度与建房配额必须在服务端卡；插件只上报用量。这样插件被人改了 JS，也拿不到没买的额度。

## 6. 记账与对账（纯本地，够用）

`tools/license-cli.mjs` 把每张码写进 `<用户目录>/.agentdeck-issuer/orders.json`：时间、档位、客户名、有效期、码的指纹（不是整串）。
每月对一次：订单表里的行数 × 单价 ≈ 爱发电到账金额。对不上就是有漏发/重复发。

## 7. 合规与边界（别踩）

- 个人收款：先用爱发电等平台代收（平台代扣税、有订单凭证），别直接大规模走个人收款码。
- 别承诺"永久"：最长卖 3 年，写清到期日。
- 别卖"破解版/内部版"之类模糊说辞；三档权益在 `lib/license.js` 的 `TIERS` 里是**公开可查**的，说清楚反而增加信任。
- 开源与收费的边界写在 `LICENSE` 里：代码 MIT，托管服务和素材包收费，任何人都能自建中继自己发码。这条要主动讲，它是信任来源，不是漏洞。

## 8. 增长回路：付费的人只有一个，被拉进来的人免费（已真实跑通）

赚钱的瓶颈不是"卖得贵"，是"没人用"。所以把付费点放在**房主**身上，客人永远免费：

```text
房主付费 ¥29/月
   └─ 建云房间 → 得到两条邀请：dsh:// 深链（装了 DSH 的人）+ http://relay/?room=&t=（没装的人）
        └─ 客人打开网页加入页：一行安装命令 + 邀请码 + "你是客人，不需要买授权"
             └─ 客人装插件、进房间、一起干（免费）→ 他也会想当房主 → 下一轮
```

这条回路里每一步都已经是可运行的东西（不是设想）：

| 环节 | 实现 | 证据 |
| --- | --- | --- |
| 房主建房间要授权 | relay `POST /v1/rooms` 用内置公钥验签，坏码 402 | `docs/evidence/two-hosts-*.md`、`tests/room-two-hosts.test.mjs` |
| 客人进房间不要授权 | relay `POST /v1/rooms/:id/join` 只校验邀请码 | 同上（免费档客人 join 成功那条断言） |
| 网页加入页能被真人打开 | `GET /?room=&t=` 返回自包含 HTML（零外链） | 同上（断言含 `dsh plugin add agentdeck-super`、无外部域名） |
| 房主关房后客人优雅停下 | `pull()` 把 410 折成 `{ok:true,closed:true}` | 同上 |

**给客人的话术（网页页里已经这么写，你转发时也这么讲）：**

> 这个房间是我付费开的，你进来干活不用买任何东西。装上 `agentdeck-super`，点这个链接就入座。

**自建者怎么收自己的钱**：`node tools/license-cli.mjs init` 生成自己的密钥对 → 公钥设进 `AGENTDECK_LICENSE_PUBKEY` → 自己的 relay 只认自己的码。我们不从中抽成，也不拦（MIT 本来也拦不住），换来的是口碑和托管服务的真实对比。
