# Nexi 灵犀 1.11.4 发布说明

发布日期：2026-11-09

## 本次改动

### 1. 多设备入席可以带真实名字

成员设备加入项目房间时支持：

```powershell
node tools/nexi-pair.mjs guest --invite-file invite.txt --name "张三-设计部"
```

不传 `--name` 时默认使用本机主机名。房主执行：

```powershell
node tools/nexi-pair.mjs members
```

可以看到当前房间的席位名单，不再全是“客人”。这解决的是项目管理员无法区分
哪台设备、哪个人占了哪一席的问题。

### 2. MCP `deck_room` 的 join 动作支持 `memberName`

Agent 通过 MCP 加入房间时也可以传：

```json
{"action":"join","inviteUrl":"http://房主地址:8787/?room=...&t=...","memberName":"张三-设计部"}
```

该名字只用于房间成员显示，不参与授权判断。

### 3. 新增 `members` 命令

```powershell
node tools/nexi-pair.mjs members
```

它先同步一次，再打印完整房间信息和成员名单，供项目管理员验收席位占用。

## 边界

- 一个房间最多 200 席，企业版也是 200，**不是无限席位**；
- 同一邀请可以由多台设备使用，每台消耗 1 席，满席返回 `room_full`；
- 当前没有“管理员按员工单独签发、单独撤销”的持久控制面；
- 没有 npm 发布、MCP Registry 收录或 GitHub 1.11.4 Release；
- 本轮没有第二台物理电脑，物理验收必须由用户执行。
